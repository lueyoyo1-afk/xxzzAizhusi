使用说明

这是「蛛丝」的完整功能清单。带 ✅ 的可以直接用，带 ⚠️ 的有前提条件，带 ❌ 的当前版本用不了，别在那儿卡住。

✅ 可以用的功能
聊天
和 AI 真对话，流式输出（一个字一个字蹦），支持 Markdown 渲染、代码块、表格，回复完自动滚到底。
上下文记忆
AI 记得前面聊过什么。带多少条在「我 → 上下文条数」里调，0 = 不带历史。条数越多越贵，缓存命中能便宜很多。
多个会话
「消息」页可以建多个对话，长按或左滑能删除。会话列表左滑删除时别滑太靠边，靠边是唤出侧边栏的手势。
发图片（识图）
点输入框左边的回形针选图，可以发给 AI 让它看图。一次只能发一张。图片只用于当次发送，不会长期存在手机里（关掉就没了）。
人设卡
在「我 → 人设卡」里建多张卡，每张一套性格设定，切换卡就等于换个人格聊天。内置的「像素蜘蛛」卡不可删。卡上右侧「⋯」可编辑、重命名、删除。
API Key 管理
支持存多个 Key，随时切换。Key 只存在这台手机里，不上传。点眼睛图标可以查看明文。
模型切换
「我 → AI 模型」里选。deepseek-flash 快而便宜，支持看图；deepseek-v4-pro 更强更贵，不支持看图。
动态（朋友圈）
「动态」页可以发图文动态，纯本地，只有你自己看得到。
个性装扮
「我 → 个性装扮」里换主题配色、圆角、聊天背景（纯色或自己的图，可裁剪）、字体。改了立刻生效。
会话「⋯」菜单
聊天页右上角「⋯」里藏着一堆操作：重命名会话、重新生成回复、复制最后回复、搜索本会话、聊天背景、导出此会话、清空此会话、删除此会话。不知道命令在哪儿找的，先点这里。
联系人「⋯」开关
点联系人详情右上角「⋯」可开关：让 TA 自己发朋友圈、主动评论互动、显示思考、显示推理过程。关掉后对应行为就不会发生。
对话姿态
聊天页右上角有个姿态按钮，点开可选四档：认真事务、情感剖白、角色扮演、抽离讨论。换档后在下一轮回复生效，档位会记住，下次打开还是那一档。
数据备份 / 恢复
在「关于」页最下面。导出会生成一个 JSON 文件，含全部会话、动态、人设卡和设置。换手机或者要清数据前，先导一份。
⚠️ 有前提条件的功能
发图片需要选对模型
deepseek-flash 能识图；deepseek-v4-pro 不支持图像理解。用 Pro 发图，AI 是「看不见」的，别以为它装傻。
附件必须在系统文件里先存在
选图走的是系统文件选择器。如果某个 App 保存的图选不到，先把它存到「下载」目录再选，基本都能解决。
花钱的事
用的是你自己的 DeepSeek Key，按量计费。高峰时段（周一至周五 9:00-12:00、14:00-18:00）单价贵一倍左右，其余时段便宜。多轮对话别老是清空历史，缓存命中的价格差几十倍。
本地存储有上限
所有数据存在浏览器本地存储里，长期不用又不清理，可能会满。「关于」页能看到当前占用。满了就导出备份后清一次。
❌ 当前版本没有 / 用不了
联网搜索
这个功能已经整个拆掉了。AI 只知道训练时的事，问它实时新闻、今天的天气、最新股价，它答不了，别指望。
一次发多张图
目前只支持单张。要发多张就一张张来。
语音输入 / 朗读
没有。所有输入都靠打字。
云端同步 / 多设备
没有账号系统，数据只在这台手机上。换手机请用「导出备份 → 导入备份」。
重新生成 / 编辑已发出的消息
没有这两个按钮。想改就让 AI 重说一遍，或者删掉这个会话重开。
AI 主动发消息 / 定时提醒
没有。App 关了就完全停了，不会有任何后台推送。
📌 一些特殊情况说明
改了设置但没生效？
Key、模型这类改完点「保存」才生效；温度和最大长度是「下次发送」生效，不会影响已经发出的消息。
清空数据的后果
「清空全部数据」会删掉会话、动态、人设卡，但会保留你的 API Key、模型选择和设置。清之前强烈建议先导备份。
AI 回复特别慢或报错
多半是 Key 没配额了、网络断了，或者服务商在高峰期排队。先在「关于」页确认接口地址和模型对不对，再检查 Key 余额。
它是给自己用的
不上架、不分享、不做技术支持。把它当个顺手的私人工具就行。
说明可能随版本更新而略有出入，以实际界面为准。
